# Развёртывание RouteMap

Публичный экземпляр пока не развёрнут. Локальный адрес: http://127.0.0.1:8000.
После запуска облачного сервиса добавьте его фактический HTTPS-адрес в начало
README, укажите режим `live` и ветку `main`.

Frontend и API обслуживает один FastAPI-процесс. Для текущей версии используйте
один экземпляр и один worker: сессии и счётчик бюджета хранятся в памяти и
сбрасываются при перезапуске. GPU не нужен — модели вызываются через OpenAI API.

## Render Free

1. Создайте Web Service из GitHub-репозитория, ветка `main`.
2. Выберите Python 3 и тариф Free. Корневая папка — корень репозитория.
3. Build Command: `pip install -r requirements.txt`.
4. Start Command: `python -m uvicorn backend.platform.app:app --host 0.0.0.0 --port $PORT --workers 1`.
5. Health Check Path: `/api/health`.
6. В настройках Environment задайте `APP_MODE=live`, `OPENAI_API_KEY` и остальные
   переменные из `.env.example`. Для воспроизводимости выберите Python 3.12
   согласно [инструкции Render](https://render.com/docs/python-version).
   Значение ключа добавляйте через настройки сервиса, не в Git.
7. После сборки откройте выданный HTTPS-адрес, проверьте `/api/health`, текстовый
   ход и микрофон. После этого публикуйте ссылку в README.

Сервис засыпает после 15 минут без входящего трафика; пробуждение занимает
около минуты. Бесплатная квота — 750 часов на workspace в месяц. Возможны
перезапуски и другие лимиты. Перед демонстрацией откройте сайт заранее.
Источники: [FastAPI на Render](https://render.com/docs/deploy-fastapi),
[условия бесплатного тарифа](https://render.com/docs/free).

## Другие варианты

- [Railway](https://docs.railway.com/pricing/plans): стартовый trial-кредит $5,
  Free — $1 кредита в месяц, Hobby — $5 в месяц; фактическая стоимость зависит
  от потребления ресурсов. Бесплатный лимит не гарантирует постоянную работу.
- [Hugging Face Spaces](https://huggingface.co/docs/hub/spaces-overview):
  создание Docker Space сейчас требует платного плана; бесплатные Static Spaces
  не запускают наш Python-бэкенд.

Условия проверены 23 сентября 2026 года. Бесплатный хостинг не оплачивает OpenAI.
В текущем приложении нет авторизации посетителей: общий локальный лимит действует
до перезапуска процесса. Для публичного демо контролируйте расходы и доступ;
для длительного размещения нужны постоянный учёт бюджета и защита API от злоупотреблений.

## Ветка для ускорения

Эксперименты — в `feat/try_upgr_perf`; размещённое демо собирается из `main`.
Сначала фиксируем сопоставимый baseline STT/LLM/TTS/end-to-audio, затем измеряем
эффект каждого изменения и проверяем качество RU/KK/EN и смешанной речи.
Изменения переносятся в `main` после проверки каждого эксперимента.
