| Требование | Ответственный | Проверка |
|---|---|---|
| LLM выбирает сценарии | 1 | Live model call + structured output; no phrase mapping |
| Все 40 + 3 SYS, multi-intent | 1 | Official evaluate.py over 104 dev utterances; separate holdout |
| Контекст, смена и возврат темы | 1 | 10 dialogs_sample + новые последовательности |
| RU/KK/mixed | 1+2+3 | Текстовая оценка отдельно от live microphone tests |
| STT/TTS адаптеры, API и воспроизведение | 1+2+3 | Неподготовленная реплика в микрофон и слышимый ответ |
| Данные Saqta, идентификация | 2 | Ответ по knowledge_base/mock_backend с реальным mock lookup |
| Подтверждение действий | 2 | Нет execute без confirm; смена параметров отменяет confirm |
| Передача оператору | 2+3 | Контекст, причины, слоты; симуляция явно помечена |
| Трассировка | 3 | Каждая реплика: IDs, rationale, alternatives, timings |
| Задержка | 2+3 | p50/p95 + sample size; mouth-to-ear отдельно от router |
| Лимиты расходов | 2 | Нельзя live без лимита; учёт retries/STT/TTS/LLM |
| README и запуск | 2 | Чистый clone, install, python run.py, offline tests |

## Контрольные точки
- Сначала: каждый запускает scaffold и понимает свою папку/контракт.
- Первый вертикальный срез: текст → реальный Router → UI trace; ограниченный live smoke.
- Затем: микрофон → STT → Router → grounded reply → TTS.
- Затем: все 104 dev-реплики, системные намерения, подтверждения и возврат темы.
- Последние 60–90 минут перед дедлайном: freeze возможностей, исправления, clean-clone
  репетиция, README, demo. Дедлайн уточняется командой; длительности — порядок работы.

## Финальный demo
Показать SC30 + SC29, urgent-first, RU→KK/смешанную речь, возврат к отложенной теме,
неоднозначный запрос → уточнение, неверный идентификатор → recovery/handoff,
необратимое действие → preview → подтверждение.
Примеры придумать самостоятельно; жюри вводит новые реплики.
Для каждого show: выбранные ID, альтернативы, краткое основание, реальные times.
Не заявлять результаты без live прогона. Offline scaffold tests не доказывают routing accuracy.
