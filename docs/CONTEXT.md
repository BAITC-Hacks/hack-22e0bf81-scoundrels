## Продукт
RouteMap — веб-симулятор голосового контакт-центра вымышленной Saqta Insurance.
Клиент говорит, система распознаёт, LLM выбирает один или несколько сценариев,
исполнитель использует факты/мок-действия, клиент слышит ответ. Супервизор видит
транскрипт, выбранные сценарии, альтернативы, краткое объяснение и измерения.

Отличительная функция: текущая тема + очередь/стек отложенных тем.
Смена темы не удаляет предыдущие слоты; после завершения можно вернуться.
Срочные SC11 / SC15 / SC38 обслуживаются прежде остальных намерений.

## Must-have к финальной сдаче (каркас ещё не выполняет их все)
1. Реальный микрофон → STT → LLM routing → обоснованный ответ → слышимый TTS.
2. LLM принимает содержательное решение, а не только перефразирует ответ.
3. Полный исходный каталог, системные намерения, смена темы и смешанная речь.
4. Панель трассировки после каждого хода, реальные задержки.
5. RU и KK; явно показывать затруднение и предлагать оператора.
6. Действия только поверх mock_backend; перед необратимым действием подтверждение.
7. Запуск одной командой после установки зависимостей; воспроизводимый README.

## Приоритеты и ограничения
Сначала рабочий полный голосовой путь и качество маршрутизации, затем ускорение.
Ориентир router = 500 мс; от конца речи до начала аудио = 1.5 с.
Это цели, не обещанная производительность. Backend time НЕ равно mouth-to-ear.
Не оптимизировать точность под известные проверочные фразы.

OpenAI API работает; у каждого участника USD 50. NVIDIA пока недоступен из-за
верификации; его кредиты не включаем в доступный бюджет.
Никакие ключи не храним в Git. Бюджетные env-поля в каркасе пока не исполняются.
Браузерный TTS не гарантирует казахский; планируем серверный TTS и проверяем звучание.
