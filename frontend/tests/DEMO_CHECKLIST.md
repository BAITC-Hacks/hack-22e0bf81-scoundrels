# Чек-лист демонстрации и приёмки UI (Role 3: Frontend / UX)

Данный документ предназначен для ручной проверки в реальных браузерах (Google Chrome, Microsoft Edge) при локальном запуске (`python run.py`, http://127.0.0.1:8000).

---

## 1. Базовый запуск и отображение (Pre-flight check)
- [ ] Сервер запущен: `python run.py`.
- [ ] Открыть http://127.0.0.1:8000 в Chrome или Edge.
- [ ] В шапке отображается статус:
  - `Подключено` (зеленый бейдж).
  - Сгенерированный `session_id` (например, `Сессия: a1b2c3d4…`).
  - Желтый баннер: `Режим scaffold: LLM и голосовые endpoints ещё не подключены. Проверяется контракт API.`
- [ ] Правая колонка («Панель супервизора») содержит статус ожидания реплики.

---

## 2. Текстовый диалог (Резервный и основной рабочий канал)
- [ ] Ввести реплику на русском: `Здравствуйте, хочу оформить полис ОГПО в Алматы`.
- [ ] Нажать кнопку `Отправить текст` (или Enter).
- [ ] Кнопка отправки блокируется во время запроса (`Отправка…`), предотвращая повторные клики.
- [ ] Появляется ответ ассистента в бабле слева.
- [ ] Счётчик ходов увеличивается: `Ход 1 / 10`.
- [ ] В панели супервизора отображается:
  - Бейдж режима (`SCAFFOLD MODE`).
  - Карточка действия (`route` / `clarify` / `transfer`).
  - Раздел «Извлечённые слоты» и «Управление темами».
  - Водопад задержек (Router ms, Backend Total ms, дефисы `—` для неизмеренных этапов).

---

## 3. Двуязычность и код-свитчинг (RU / KK)
- [ ] Переключить селектор языка UI в шапке на `KK (Қазақша)`.
  - Все надписи интерфейса переключаются на казахский язык (`Клиент арнасы`, `Супервизор панелі`, `Мәтінді жіберу`, `Жаңа әңгіме`).
- [ ] Отправить казахскую реплику: `Сәлеметсіз бе, КАСКО сақтандыруын қалай есептеуге болады?`.
- [ ] Отправить смешанную реплику (код-свитчинг): `Сәлеметсіз бе, вчера оплатил полис, а он не пришел`.
- [ ] Проверить, что поле `language` корректно отправляется на бэкенд.

---

## 4. Проверка микрофона (Push-to-Talk) и STT
- [ ] Нажать и удерживать кнопку `🎙️ Микрофон (PTT)`.
- [ ] Браузер запрашивает разрешение на доступ к микрофону.
  - **Случай А (Отказ):** отклонить доступ → выводится понятное сообщение: «Доступ к микрофону отклонен пользователем или политикой браузера».
  - **Случай Б (Разрешение):** разрешить доступ → кнопка пульсирует красным, текст меняется на `Идет запись… Отпустите для отправки`.
- [ ] Отпустить кнопку микрофона:
  - Запись останавливается, фиксируется `speechEndTimestamp` через `performance.now()`.
  - Аудиофайл отправляется в `POST /api/voice/transcribe`.
  - В режиме scaffold сервер честно возвращает HTTP 501 → в UI отображается статус: `Голосовой ввод (STT) честно возвращает HTTP 501 в scaffold-режиме. Используйте текстовый ввод.`
  - Приложение не падает, текстовый ввод остаётся активным.

---

## 5. Замер задержек и сводные метрики (p50 / p95)
- [ ] Карточка «Замеры задержек (Latency Waterfall)»:
  - Все неизмеренные серверные этапы честно отображаются как `—`, а **НЕ `0 ms`**.
  - Роутер сравнивается с таргетом `≤ 500 мс`.
  - Client End-to-Audio сравнивается с таргетом `≤ 1500 мс`.
- [ ] Нижняя плашка сессионных статистик отображает:
  - Число успешных голосовых замеров.
  - `p50 (медиана)` и `p95` сквозной задержки.
  - Подсветку бонусных баллов жюри (≤ 1.5 с — +2 балла; ≤ 3.0 с — +1 балл).

---

## 6. Лимит 10 ходов и сброс сессии
- [ ] Отправить 10 реплик подряд в одной сессии.
- [ ] На 10-м ходе:
  - Счётчик окрашивается в красный цвет: `Ход 10 / 10`.
  - Поля ввода блокируются с предупреждением: «Достигнут лимит 10 реплик для текущей сессии. Пожалуйста, начните новый разговор».
  - Попытка отправить 11-й ход отклоняется (или сервер возвращает 409).
- [ ] Нажать `🔄 Новый разговор`:
  - Создаётся свежая сессия (`POST /api/sessions`).
  - Счётчик сбрасывается в `Ход 0 / 10`.
  - Поле ввода и кнопки снова активны.

---

## 7. Replay и эталонные образцы датасета
- [ ] **Экспорт сессии:** после 1-2 ходов нажать `💾 Экспорт сессии` → скачивается валидный JSON-файл `routemap-trace-*.json`.
- [ ] **Импорт Replay:** нажать `📂 Загрузить Replay` и выбрать сохраненный файл → в панели отображается трасса с ярким бейджем `[REPLAY]`.
- [ ] **Образцы датасета:**
  - В выпадающем списке выбрать `D03: Смена темы (SC17 → SC27 → SC18)`.
  - Панель супервизора отображает эталонную цепочку с бейджем `[DATASET SAMPLE]`, показ стека тем (`parked`, `active`) и переключение сценариев.
  - Выбрать `D05: Уточнение (SYS_UNCLEAR)` → отображается желтый блок уточняющего вопроса.
  - Выбрать `D06: Жалоба и оператор (SC35 → SC37)` → отображается статус перевода на оператора (`transfer`).
