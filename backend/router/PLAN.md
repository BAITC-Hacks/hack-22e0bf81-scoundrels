# AI Router: 9 этапов

Ветка `feat/router`, изменения только `backend/router/**`.
Ориентир — 25–35 минут на этап, но это оценка, а не искусственная задержка.
Commit + push осмысленного прогресса примерно раз в 30 минут активной работы.
Платные проверки не запускать автоматически; не создавать пустые коммиты.

| № | Результат этапа | Проверяемая готовность |
|---|---|---|
| 1 | Контекст, границы роли, исходные проверки | Чистая своя ветка; известны ограничения платформы |
| 2 | Каталог и промпт | Все 43 ID, not_this_if, RU/KK и описания слотов доступны LLM |
| 3 | OpenAI provider | Structured output; injected client; timeout, лимиты, отказ без fake fallback |
| 4 | Routing policy | Urgent first, остальные по порядку; валидация ID и подтверждения |
| 5 | Темы и слоты | Create/continue/switch/park/resume/resolve без смешивания сессий |
| 6 | Системные намерения | Уточнение, повторная неясность → оператор, goodbye/out-of-scope |
| 7 | Eval | Predictions из Decision; официальный evaluate.py; языковые срезы |
| 8 | Интеграция offline | Реальный SDK с mock transport; контракт API и demo диалог |
| 9 | Передача | TASKS/HANDOFF, ограничения, команды запуска, commit + push |

## Внешние критерии, которые нельзя подтвердить mock-тестами

- Точность настоящей модели на 104 dev-репликах: только явно разрешённый live eval.
- Работа голосового приложения: подключение provider/budget/executor/STT/TTS ролью 2.
- Реальная задержка LLM и качество казахского языка: только live-измерения.
