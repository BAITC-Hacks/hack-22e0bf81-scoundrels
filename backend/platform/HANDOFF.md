# Platform / Integration handoff

Обновление `feat/try_upgr_perf`: `/api/voice/synthesize/stream` передаёт MP3
частями и держит бюджетный/concurrency слот до закрытия потока. Старый endpoint
сохранён. Ошибки до первого чанка — 429/502; поздние ошибки обрывают поток.
Результаты, проверки отмены и инструкция: `docs/PERFORMANCE.md`.

Интеграция сделана прямо в `main` по запросу владельца проекта, поскольку
удалённая `feat/backend` оставалась на исходном scaffold. Перед будущим merge
этой ветки сравнить её с main; не переписывать работающий путь вслепую.

## Реализовано

- `APP_MODE=scaffold` остаётся бесплатным режимом по умолчанию.
- `APP_MODE=live` запускается только с ключом, проверенными моделями и
  положительными лимитами. `gpt-6-luna` + `gpt-transcribe`/mini +
  `gpt-4o-mini-tts`; SDK retries = 0.
- `/api/sessions/{id}/turns` делает один LLM-вызов, сохраняет историю/темы
  лишь после валидного решения, возвращает язык, фактический router timing
  и осторожный ответ из официальных данных.
- `/api/voice/transcribe` принимает до 1 MiB аудио допустимого MIME;
  `/api/voice/synthesize` отдаёт MP3 и серверные timing-заголовки.
- `DemoBudget` заранее резервирует $0.02 на один вызов каждого типа,
  ограничивает run/session и max 2 concurrent paid calls. Резерв не
  возвращается после ошибки. Это консервативный локальный limiter, **не**
  доказанный upper bound счёта провайдера и не замена project spend limit.
- Read-only ответы: SC25 полис, SC17 обращение (оба требуют совпадения номера
  с зарегистрированным телефоном), SC31 способы оплаты, SC33 адреса офисов.
  Прочие сценарии используют opening из starter-kit; мутации не выполняются.
- Язык `en` добавлен в wire contract для английской речи. Для mixed реплики
  язык ответа выбирается эвристикой только для текста ответа, не для маршрута.

## Проверки

`python -m pytest -q`: 75 offline tests перед push. Paid HTTP smoke на сохранённом KK/EN MP3 дважды
получил `[SC25, SC29]`, а после UX-исправления ответ был на казахском и
упомянул обе задачи. Browser UI вручную проверен: текстовый ход с SC25 и
голосовой ход от микрофона через STT→LLM→TTS. В голосовом ходе браузер
измерил end-to-audio ≈9.6 s — бонусный порог не достигнут.

## Что ещё не завершено

Необратимые действия, SMS и реальный operator queue. По ним ответ не должен
утверждать, что действие выполнено. Для полной конкурсной реализации нужны
confirmation flow, idempotency и дополнительные data-backed исполнители.
Демо рассчитано на один процесс: сессии и бюджет теряются при перезапуске,
несколько workers запрещены. Для публичной эксплуатации требуется отдельная
аутентификация, стойкое хранилище и provider-side spending control.
